# 🎲 Dice Roll Game

A simple Dice Roll Game built using **React.js** and **Tailwind CSS**.

## 🎯 Project Goal

Create a small interactive game where the user clicks a button to roll a dice.

Every time the button is clicked:

- Generate a random number from **1 to 6**
- Display the random number
- Change the dice emoji/image according to the number
- Show the result on the screen

---

## 🛠️ Technologies

- React.js
- Tailwind CSS
- JavaScript
- React `useState`
