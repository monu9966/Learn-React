# Guess Number Game
Generate the random number 
Guess user random number if guess correct then user win
if not user lose

Choose option Easy, Medium and Hard Level

if Easy Attemts 10
if Medium Attempts 7
if Hard Attempts 5

🗺️ The Architecture & State DesignTo build this app, we need to track four key pieces of data in our component's state:

targetNumber: The secret random number generated by the system.

userGuess: The current value typed into the input box.

feedback: The hint given to the player (e.g., "Too high!", "Too low!", "You won!").

attempts: The number of guesses the user has made so far.
